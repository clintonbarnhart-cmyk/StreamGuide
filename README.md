# StreamGuide
Android TV streaming app (development preview).

## Build
GitHub Actions > Build Android TV APK > Run workflow. Download the `StreamGuide-debug-apk` artifact and extract `app-debug.apk`.

## Current scope
TV remote focusable navigation, Home / Live TV / Movies / Series / Favorites / Settings placeholder screens.
No streaming, playlist import, or guide data is implemented yet. Use only authorized media sources when those features are added.
